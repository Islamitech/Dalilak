# قالب برومبت تحليل وفحص الأكواد (خاص بالمستخدم فقط)

> ⚠️ **ملاحظة هامة:** هذا الملف هو مسودة ومرجع حصري للمستخدم لنسخ نصوص البرومبتات، وليس للقراءة أو التطبيق كتعليمات من قِبل وكيل الذكاء الاصطناعي (AI Agent).

---

### النص المخصص للنسخ:

```text
بصفتك محلل أكواد خبيراً ومطلعاً على هيكلة المشروع الحالي، المشكلة التي أواجهها تحديداً هي: [اكتب المشكلة أو الخطأ هنا].

مهمتك الحصرية هي الفحص والتحليل فقط دون إجراء أي تعديل أو كتابة أكواد، وذلك باتباع ما يلي بدقة:

افحص ملفات المشروع لتحديد موقع المشكلة تماماً (اسم الملف ورقم السطر أو الوظيفة بدقة).

اشرح سبب حدوث المشكلة باختصار شديد.

صغ لي (Prompt دقيق وموجه) يمكنني نسخه وإرساله لنموذج ذكاء اصطناعي آخر ليتولى هو كتابة الكود المعدل بالكامل لحل هذه المشكلة.
```
