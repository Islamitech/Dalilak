# 🗺️ دليلك • بوابة ودليل الأنشطة والخدمات المعتمدة (Dalelak Public Directory)

نسخة معمارية مستقلة تماماً ومخصصة حصرياً للعملاء والجمهور العام وأصحاب الأنشطة التجارية في مصر.

🌐 **الدومين الرسمي المعتمد:** [https://www.dalilaak.com](https://www.dalilaak.com)  
⚡ **استضافة Vercel المستقلة:** [https://dalilak-directory.vercel.app](https://dalilak-directory.vercel.app)

---

## 🌟 المبادئ المعمارية للسيادة والاستقلالية:
1. **انفصال كامل ومحكم عن المنظومة الإدارية (Zero-PII / Zero-Admin):**
   - خالية 100% من أي شاشات لتسجيل الدخول، لوحات تحكم الإدارة، بيانات المناديب، أو أسرار النظام.
   - لا يمكن لأي زائر الوصول إلى أي بيانات حساسة أو فواتير أو مستندات هوية.
2. **اتصال سحابي مباشر مع Supabase Cloud SSOT:**
   - مصدر الحقيقة الموحد للأنشطة والمحلات الموثقة والمعتمدة فور تسجيلها ونشرها.
3. **خريطة تفاعلية وفلاتر جغرافية ذكية:**
   - تصفح واستكشاف حسب المحافظة والتصنيف الجغرافي والبحث باللغة العربية.
4. **محرك SEO وبيانات منظمة متقدمة:**
   - وسوم OpenGraph و Twitter Cards مخصصة لكل نشاط.
   - بيانات منظمة Schema.org (`LocalBusiness`, `Store`, `Restaurant`, `MedicalBusiness`) بصيغة JSON-LD.
   - خريطة موقع ديناميكية محدثة سحابياً عبر المسار `/sitemap.xml`.
   - روابط دائمة معيارية (`/biz/:id`).
5. **معاينة صور عالية الدقة وتصفح Lightbox كامل.**
