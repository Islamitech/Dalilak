# 🗺️ دليلك • بوابة ودليل الأنشطة والخدمات المعتمدة (Dalelak Public Directory)

نسخة مستقلة تماماً ومخصصة للعملاء والجمهور العام وأصحاب الأنشطة التجارية في مصر.

## 🌟 المميزات:
1. **خالية تماماً من شاشات تسجيل الدخول وأدوات الإدارة:** لا يمكن لأي زائر الوصول إلى حسابات المناديب أو فواتير الأرباح أو بيانات المنظومة الداخلية.
2. **اتصال سحابي فوري ومباشر مع Supabase:** تعرض الأنشطة والمحلات فور تسجيلها على المنظومة وتحديث إحداثياتها وصورها.
3. **خريطة تفاعلية وفلاتر جغرافية:** تصفح حسب المحافظة (افتراضي الجيزة) والتصنيف والبحث السريع.
4. **باقات التوثيق وطلب الاستشارات عبر واتساب مباشرة.**

---

## 🚀 كيفية الرفع والاستضافة على GitHub كـ Repository مستقل:
1. أنشئ مستودعاً جديداً على حسابك في GitHub باسم: `dalelak-directory`.
2. افتح مجلد `dalelak-directory-portal` في التيرمينال ونفذ الأوامر التالية:
```bash
cd dalelak-directory-portal
git init
git add .
git commit -m "Initial commit: Dalelak standalone public directory"
git branch -M main
git remote add origin https://github.com/Islamitech/dalelak-directory.git
git push -u origin main
```
3. يمكنك ربطه بـ **Vercel** أو **Netlify** أو **GitHub Pages** بضغطة زر مجاناً للأبد!
