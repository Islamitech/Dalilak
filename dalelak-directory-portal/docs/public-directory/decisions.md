# قرارات النسخة المستقلة

1. **النطاق المعتمد:** طلب المستخدم نسخة مستقلة تحاكي تجربة الدليل. مدخل HTML وإعداد Vite منفصلان، دون استبدال مدخل الإنتاج أو تعديل إعداداته. لا يحتاج هذا القرار إلى تأكيد جديد.
2. **التقنية:** React / TypeScript / Tailwind / Lucide الموجودة بالفعل. لا حزم جديدة ولا مشروع Backend.
3. **البيانات:** fixtures.ts هو المصدر الوحيد للمحتوى التجريبي. الصور محلية توضيحية. تستقبل الواجهة DirectoryCatalog؛ لا تستورد الشاشات البيانات التجريبية.
4. **الخريطة:** SVG محلي بإسقاط جغرافي للمناطق الصغيرة؛ سحب وتكبير ولمس وتجميع علامات متقاربة. يعرض مناطق وبوابات المشروع دون بلاطات خارجية أو مفاتيح أو طلبات شبكة. ليس بديلًا نهائيًا لمحرك الملاحة أو خريطة الشوارع.
5. **مرجعية الجغرافيا:** قراءة HADAYEK_OFFICIAL_DISTRICTS وHADAYEK_OFFICIAL_GATES من ملف المشروع الموجود. اسم الثابت لا يثبت اعتماد الحدود؛ تنبيه الملف يقول إن المضلعات محلية وإرشادية. اختلاف مناطق خدمة بعض البوابات بين ملفات الأطلس يستلزم مراجعة مالك البيانات قبل النشر؛ استُخدم مصدر واحد بصورة متسقة.
6. **المناطق والبوابات:** 16 منطقة، 6 بوابات. اختيار المنطقة يفلتر الأماكن والبوابات المرتبطة، واختيار بوابة يعيد عرض المناطق كلها ويركز موقع البوابة. تفاصيل التحديد خارج الخريطة لتقليل حجبها.
7. **المواقع:** أسماء الأنشطة وعناوينها ونقاطها افتراضية. بحث رقم العمارة يشرح نتيجة المحاكاة ولا يضع دبوسًا مخمّنًا. دقة عنوان العمارة قرار بيانات لاحق.
8. **الخصوصية والأمان:** لا طلب لموقع الجهاز، لا إرسال أو اتصال أو تنزيل جهات اتصال، ولا تخزين مسودة في المتصفح. إجراءاتها نوافذ محاكاة صريحة. حفظ المسودة والمفضلة في الذاكرة طوال جلسة المعاينة فقط.
9. **التنقل:** hash routes للمعاينة. إبقاء الصفحات المزارة مركبة يحفظ المسودات والفلاتر. عند الدمج الإنتاجي يستبدل ذلك بموجّه التطبيق وحالة محددة العمر.
10. **الوصولية:** تسميات وfocus-visible، احتجاز تركيز النوافذ وEscape واستعادة التركيز، رسائل status/alert، دعم reduced-motion. دعم LTR هنا اختبار تخطيط وليس ترجمة إنجليزية.
11. **الفيديو:** لا ملف فيديو مناسب ضمن هذه النسخة؛ المشغّل محاكاة حالة تشغيل/إيقاف مع تصريح واضح، وليس تشغيل فيديو فعليًا.
12. **الأسعار والصلاحيات:** الأسعار في fixtures أمثلة عرض غير ملزمة. unauthorized حالة عرض فقط؛ تحديد قواعد وصول فعلية يتطلب صاحب النظام. لا توجد شاشة إدارة لأن المهمة للدليل العام.

## قرارات مطلوبة قبل الدمج الإنتاجي

- اعتماد مصدر وحدود المناطق والبوابات وإحداثيات العمارات والأماكن.
- تحديد مزود خريطة الشوارع والملاحة إن كان مطلوبًا، وشروط العرض والترخيص.
- اعتماد النصوص والباقات والأسعار والأصول الإعلامية.
- تحديد عقد بيانات public آمن وحالات الطلب والصلاحيات من الخدمات الحالية.
- تحديد مصير المفضلة والمسودة: جلسة أم حساب أم تخزين محلي، والسياسة المناسبة لذلك.
- تحديد اللغات المدعومة؛ لا يُعتبر تبديل الاتجاه ترجمة.

## تحديثات المستخدم المعتمدة
- الخريطة هي الصفحة الرئيسية وتملأ المساحة تحت الرأس، دون عمود نتائج دائم. الاستكشاف ينتقل إلى /discover.
- ثلاثة كروت بارزة من ترتيب البيانات العام أو المنطقة، في لوحة عائمة قابلة للطي. اختيار كارت أو دبوس يعرض كارتًا موسعًا وحيدًا ويقرب الكاميرا. الرجوع يعيد الثلاثة وتحويل الكاميرا السابق في السياق نفسه. الفلاتر والبحث يحددان النتائج المتاحة؛ لا نصطنع ثلاثة إذا كان المتاح أقل.
- لكل منطقة ثلاثة أمثلة عرض ثابتة في fixtures، لا خوارزمية ترويج حقيقية. ترتيب البروز يأتي لاحقًا من عقد البيانات المعتمد.
- الشعار والألوان الأساسية أعيد استخدامهما بطلب المستخدم من public/logo.svg وsrc/index.css، دون استيراد reset الإنتاج أو تغيير ملفاته.
