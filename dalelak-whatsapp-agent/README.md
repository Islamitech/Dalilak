# 📡 تطبيق ومنظومة دليلك المستقلة للواتساب والذكاء الاصطناعي (Dalelak WhatsApp Agent)

تطبيق وميكروسيرفس مستقل تماماً لإدارة حسابات الواتساب المتعددة، والحماية الفائقة من الحظر (Anti-Ban Radar)، والرد الذاتي عبر **xAI Grok**، وتوليد وتوزيع بطاقات الهدايا وأكواد الـ QR بدقة فائقة.

---

## 🌟 مميزات المنظومة المستقلة

1. **عزل كامل وخفة متناهية (Zero-Coupling & Ultra-lightweight):**
   - يعمل بمفرده تماماً دون الحاجة لتشغيل الموقع الرئيسي لـ «دليلك» أو أي بيئة React.
   - استهلاك ذاكرة لا يتجاوز 60 ميجابايت، وزمن إقلاع فوري أقل من ثانية واحدة.
2. **محرك Baileys الأصلي المباشر:**
   - اتصال عبر WebSockets بتقنية Multi-Device الرسمية دون تشغيل متصفح خفي (Selenium/Chromium) لحماية الحسابات من الحظر.
3. **رادار الأمان وقواطع الحظر التلقائية (Circuit Breakers):**
   - مراقبة سرعة الإرسال بالساعة (افتراضياً 40 رسالة/ساعة).
   - احتساب مؤشر المخاطرة الذاتي وفصل الإرسال تلقائياً عند أي خطر.
4. **تكامل متقدم مع xAI Grok:**
   - دعم كامل لـ `grok-2-mini` و `grok-2` و `grok-2-vision`.
   - تنفيذ ذاتي للأدوات: إرسال الهدية وكود الـ QR، تحديث بيانات النشاط، تعيين زيارات للمناديب، وتصعيد الحالات للإدارة.
   - محاكاة الكتابة الطبيعية (3.5 – 6.5 ثوانٍ).
5. **لوحة تحكم إدارية مدمجة (Embedded Web Dashboard):**
   - افتح المتصفح على `http://localhost:3005` لتجد لوحة تحكم كاملة وعصرية لمراقبة الخطوط، كتم الـ AI، وإدارة إعدادات Grok.
6. **دعم التكامل البرمجي عبر Python:**
   - توفير واجهات REST API كاملة لتمكين أي سكربت بايثون من التحكم والاستعلام (راجع `python_client_example.py`).

## 🚀 طريقة التشغيل السريع (Quick Start)

### على نظام Windows:
فقط انقر نقراً مزدوجاً على:
```cmd
run.bat
```
أو عبر سطر الأوامر:
```bash
cd dalelak-whatsapp-agent
npm install
npm start
```

ثم افتح لوحة التحكم في المتصفح:
👉 **http://localhost:3005**

---

## ⚙️ التكوين وإعدادات البيئة (`.env`)

```env
PORT=3005
HOST=0.0.0.0
GROK_API_KEY=xai-your-api-key-here
GROK_MODEL=grok-2-mini
```
*(ملاحظة: يمكنك أيضاً إدخال مفتاح Grok وتعديل النموذج مباشرة من داخل لوحة التحكم عبر زر «إعدادات Grok»).*

